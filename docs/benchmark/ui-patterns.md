# UI Patterns

## Confirmed benchmark pattern

- Centered profile card over Telegram's pale green patterned background.
- Strong single Start Bot CTA.

## Original Project 12 Demo system

- Midnight navy canvas, teal trust accent, muted gold for state emphasis.
- Full-screen mobile shell with safe-area padding.
- Large balance and round-centre hierarchy.
- Compact status badges, progressive mission bars and bottom navigation.
- Fairness proof is visible in the round, not hidden in a separate chat message.

No opponent artwork, logo or proprietary copy is reused.
