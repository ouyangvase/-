# Referral Flow

Demo-only path:

1. User enters or receives a referral code.
2. Server assigns the first valid referrer once; self-referral is rejected.
3. A qualified edge is created only after demo activity meets the campaign version.
4. Rewards are points or badges, never cash.
5. Risk signals can move an edge to `REVIEW`, `HELD` or `REJECTED` with a visible reason.
