# Real-Money Go-Live Gate

This project is not cleared for real money. `REAL_MONEY_ENABLED`, `TOP_UP_ENABLED`, `WITHDRAWAL_ENABLED` and `CASH_REWARD_ENABLED` must remain `false`; `PACKET_PROVIDER` must remain `demo`.

Before any future change, obtain written legal advice for Malaysia and each target market, age restrictions, KYC/AML/sanctions, PDPA data handling, responsible gaming, segregated funds, authorized payment provider approval, TNG written authorization, security review, penetration test, refunds/disputes, incident response, reconciliation, tax/accounting and accountable operations ownership.

Opening a payment URL is not proof of provider authorization. No personal or agent bank/e-wallet accounts may process platform funds.
