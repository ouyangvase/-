# Project 12 决策记录

## 2026-08-23：游戏场景使用 Mini App 内部聊天室

Telegram Bot 只负责私聊入口和通知；Telegram 原生群聊不是游戏状态源。房间消息、轮次、红包资格和账本由 API/Postgres 维护，Realtime/SSE 只负责把已授权的事件送到客户端。

## 2026-08-23：所有游戏动作使用文字指令

玩家在同一个 Composer 发送数字、`抢庄 600`、`sh50`、`停止下注`、庄家确认文字或 `抢红包`。前端不提供下注按钮，服务端按当前轮次、身份、余额和幂等键解析并拒绝非法动作。

## 2026-08-23：红包按参与者隔离

公开时间线只显示平台状态；专属红包卡和领取资格按 `round_participants`/`packet_allocations` 在服务端过滤。旁观者不能通过修改前端状态取得 Claim Token。

## 2026-08-23：真实现金保持关闭

当前只允许 Demo 积分路径。钱包、充值、提现和 TNG 资金动作在没有合规、供应商和资金授权前不能开启；这不是 Telegram 或 UI 部署完成的替代品。
