# User Stories

- As a demo player, I can understand that credits have no cash value before joining.
- As a demo player, I can see the server round state, not only a client countdown.
- As a demo player, I can repeat a click without creating a duplicate bet or claim.
- As a demo player, I can inspect the seed hash, input and rule version used for my packet.
- As an operator, I can inspect every round event and ledger journal without deleting history.
- As a risk reviewer, I can see why a referral is held before resolving it.
