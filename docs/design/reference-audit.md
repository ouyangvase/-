## Deliberate exclusions

No cartoon bull, coin pile, red-envelope iconography, playing-card art, casino gold borders, Apple-blue primary buttons, rounded card grid, fake cash claims, or mascot-led hero. The visual metaphor is a precision mechanism: black titanium, brushed steel, smoked glass, restrained aged brass.

## Senior review rubric

The top 0.1% product/design review is not “does it look premium?” It asks:

1. Can a first-time Telegram user identify the current state, the next action, and the consequence within three seconds?
2. Does every visual imply the same operating model as the rules and ledger?
3. Does the design create trust through observable state and references rather than decorative claims?
4. Can the same system survive loading, error, reduced-motion, narrow viewport, and Telegram chrome?
5. Is the visual weight earned by product evidence, or is it merely decoration?

## Challenging the brief

The tempting interpretation is “make the app look like a luxury game.” The stronger interpretation is “make the game feel like a trustworthy instrument.” That changes the success metric from visual spectacle to state legibility, auditability, and controlled tension. The mechanism is therefore an operating surface, not a casino theme.
